# Итоговый проект: валютный кошелёк

Автор: Фёдор Симонов. Группа: М26-555.
Название проекта: `finalproject_simonov_m26_555`.

Консольное приложение, имитирующее работу валютного кошелька.
Проект оформлен как устанавливаемый Python-пакет и развивается
с использованием объектно-ориентированного подхода.

## Подготовка и запуск

Требуются Python 3.12 и uv версии 0.5 или выше. Make необязателен.
Версия Python закреплена в `.python-version`.
Выполняйте команды из директории `python/final_project`:

```sh
uv sync --locked
uv run --locked wallet
```

uv создаст виртуальное окружение `.venv` и установит зависимости
из `uv.lock`, включая сам пакет и инструменты разработки.
Альтернативный запуск:

```sh
uv run --locked python -m finalproject_simonov_m26_555
```

## Зависимости и качество кода

- `prettytable` — форматированный табличный вывод на следующих этапах.
- `ruff` — анализ и форматирование кода, зависимость только для разработки.
- `json`, `shlex`, `time` входят в стандартную библиотеку Python;
  отдельно устанавливать их не нужно.

```sh
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked ruff format .
```

Настройки Ruff: Python 3.12, длина строки 88 символов, проверки
стиля (`E`), ошибок (`F`) и порядка импортов (`I`).

При наличии Make доступны команды `make install`, `make run`,
`make check`, `make format` и `make build`.

## Сборка и установка

```sh
uv build
```

В `dist/` появятся wheel и исходный архив. Для установки wheel
в отдельное виртуальное окружение:

```sh
uv venv /tmp/finalproject-wallet
uv pip install --python /tmp/finalproject-wallet/bin/python dist/*.whl
/tmp/finalproject-wallet/bin/wallet
```

## Разработка

Используется GitHub Flow: отдельная ветка для следующей задачи,
проверки перед коммитом и осмысленный коммит после завершения этапа.
Файл `uv.lock` хранится в Git. Окружение, артефакты сборки
и кэши инструментов исключены через `.gitignore`.
